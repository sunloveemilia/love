# Shared-screen arcade

User wants actual simultaneous mini games like the 2 3 4 Player compilation, for a shared tablet. Build original canvas games with no assets/dependencies: air hockey for two; sumo, tanks and reaction for two to four. Keep existing Nearby activities unchanged. Native Sites checkout retained; user has opted out of repeated design approvals.

Implementation: lib/arcade.ts owns fixed-step deterministic simulation, inputs, scoring and validated restore. app/arcade-canvas.tsx draws the board. app/arcade.tsx owns RAF, pointer IDs, keyboard fallback, pause/countdown, match results and storage. app/arcade.css owns tablet layout. Integrate above existing TogetherExtra in Nearby.

Rules: hockey first5goals, paddle clamped to own half; sumo last standing wins a round, first3rounds; tanks idle rotates, hold moves and fires, two HP, cover, first3rounds; reaction press only after green, false start locks player out for that signal, first5points, tie on equal timestamps. No bots. Simultaneous touches tracked independently. Pause/visibility loss clears every held input. Resume with countdown; animation time never jumps after inactive tabs. Save paused snapshots on meaningful changes and unload.

Verification: tests for scoring exactly once, collision/knockout, tank wall and bullet collision, reaction false starts/ties, variable frame splitting, lost input and corrupt snapshot; browser touch controls, pauses and visible canvas.
