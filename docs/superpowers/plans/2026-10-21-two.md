# TWO Implementation Plan
Goal: A Russian mobile-first universe for two, based on docs/requirements.txt.
Architecture: React/TypeScript + Sites Worker + D1; server-owned room state with optimistic revision checks. Anonymous HttpOnly room credentials; 1.5-second snapshot polling for independent devices. API secrets server-side only.
1. Rooms: D1 rooms/rate-limit/cache schema; crypto session hashes; two-member cap; atomic revision updates. Test joins, hidden answers, stale and duplicate actions.
2. Game engine/content: 100 telepathy questions, 150 who-is-more prompts, branching stories, role-specific mission, fair wheel, impersonation ratings, personal quiz. Server computes scores and history.
3. Cinema: independent preferences, TMDB server adapter with detail revalidation (adult=false, no genre 28, runtime 90–150, released by session date), paginated browsing; independent votes; both-ready roulette; reroll consent and ticket; archive/reviews/predictions.
4. Interface: responsive dark editorial space theme, CSS orbital art, room onboarding, nine games, capsules (server-time release), universe/rewards/settings and PNG export.
5. Verification: unit engine tests + typecheck + production build; local D1 and browser QA with two sessions; package/push/deploy exact source.
Constraints: No fake movies or pretend partner. TMDB key external setup; explain missing API explicitly. No payments. Reduced motion. Russian copy. Friday 23 October 2026 default, changeable date.
Review focus: simultaneous room joins, repeated round advances, secret answer leakage, unknown runtime/action hybrids, capsule premature release.
