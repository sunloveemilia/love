# TWO — Наша маленькая вселенная

**Открыть приложение:** https://two-nasha-vselennaya.racingsnipe1.chatgpt.site

Исходники опубликованы на GitHub. Рабочие комнаты, синхронизация и база данных размещены на серверном хостинге Sites; GitHub Pages не выполняет этот серверный код.

Полноценное русскоязычное приложение для двух участников. React 19 / TypeScript / Vinext / Cloudflare Worker / D1.

## Работа приложения

- Создайте комнату, отправьте ссылку или шестизначный код второму участнику. Максимум — двое. Защищённая HttpOnly-сессия восстанавливается после перезагрузки.
- Сервер хранит состояние, раскрывает ответы только после обоих участников, проверяет раунды и считает очки. Обновления приходят опросом сервера каждые 1,5 секунды. При возврате на вкладку состояние обновляется сразу.
- Телепатия: 110 вопросов; «Кто из нас?» — 160 ситуаций; четыре ветвящихся истории, пять асимметричных миссий, честное колесо с 36 заданиями, обмен ролями, персональный квиз.
- Письма капсулы времени не выдаются получателю до серверного срока открытия. Автор может удалить своё письмо.
- Общая история, достижения по фактическим прохождениям, звёзды, украшения, избранные игры, имена/цвета профиля, необязательные синтезированные звуки.
- Cinema Date: восемь вопросов, совместные ограничения, постраничный поиск TMDB с подробной проверкой каждого фильма, независимые оценки, совпадения, общая серверная рулетка, согласование выбора, один повтор по обоюдному согласию, PNG-билет, история просмотров, прогнозы и отзывы.
- Приватные комнаты не индексируются. Секреты сессии в клиентские ответы не попадают. Приглашение другому человеку пользователь отправляет самостоятельно.

## Подключение фильмов — требуется внешний ключ

Каталог намеренно не подменяется демонстрационными фильмами. Получите свой TMDB API Read Access Token на https://www.themoviedb.org/settings/api и настройте серверную переменную `TMDB_TOKEN` в Sites. Поддерживаются Bearer Read Access Token и v3 API key. Не добавляйте значение в исходники, manifest или переменную с префиксом NEXT_PUBLIC/VITE.

Без TMDB_TOKEN работают комнаты, игры, капсула, история, достижения и киноанкета; получение фильмов, трейлеров и доступности платформ потребует ключа. В интерфейсе это явно указано. Атрибуция TMDB включена; проверенные данные о сервисах предоставлены JustWatch через TMDB. Видеофильмы приложение не транслирует.

По умолчанию 90–150 минут, все сочетания с Action (28) исключены. Horror (27) только явно. В предпочтениях поддерживаются жанры, длительность, лёгкость и эпоха; счастливый финал или сюжетный поворот не гарантируются, поскольку TMDB не даёт таких достоверных меток. Поиск также повторно проверяет жанр и десятилетие.

## Хранение и безопасность

D1: `rooms`, `movie_cache`, `rate_limits`. Записи комнат обновляются атомарно по `revision`, с повторением при конфликте. Игровые действия привязаны к ID игры/раунду, киновыбор — к ID сеанса/результата. Подготовленная подборка отклоняется, если киноанкета или дата успела измениться. Лимиты запросов, ограничение размера ввода, проверка Origin, cookie SameSite=Strict. Пароли и отдельная регистрация приложению не нужны. Шестизначный код является приглашением: передавайте его только вашему человеку.

## Проверка

```sh
node --experimental-strip-types --test tests/*.test.ts
node node_modules/typescript/bin/tsc --noEmit
node /root/.codex/plugins/cache/openai-curated-remote/sites/1.1.0/scripts/build-site.mjs
node tests/server-integration.mjs
```

Последняя команда поднимает изолированный тестовый Worker через Miniflare без браузерного сервера, применяет миграции к временной D1 и проверяет два независимых клиента, десять одновременных переходов, приватность, восстановление, лимит участников, CSRF и честную ошибку без ключа TMDB. Тестовые фильмы встречаются только в unit-тестах, не в рабочем каталоге.

Миграции: `drizzle/`; источники: `app/`, `lib/`; схема: `db/schema.ts`; конфигурация: `.openai/hosting.json`. Изменения публикуются поддерживаемым Sites workflow. `.env*` и локальные runtime-файлы не коммитятся.

PWA manifest позволяет установку в поддерживающих браузерах; работа сервера и игр требует интернета. Анимации учитывают prefers-reduced-motion.
