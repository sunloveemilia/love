# TWO — Наша маленькая вселенная

Полноценное русскоязычное приложение для двух участников. React 19 / TypeScript / Vinext / Cloudflare Worker / D1.

## Работа приложения

- Создайте комнату, отправьте ссылку или шестизначный код второму участнику. Максимум — двое. Защищённая HttpOnly-сессия восстанавливается после перезагрузки.
- Сервер хранит состояние, раскрывает ответы только после обоих участников, проверяет раунды и считает очки. Обновления приходят опросом сервера каждые 1,5 секунды. При возврате на вкладку состояние обновляется сразу.
- Телепатия: 110 вопросов; «Кто из нас?» — 160 ситуаций; четыре ветвящихся истории, пять асимметричных миссий, честное колесо с 36 заданиями, обмен ролями, персональный квиз.
- Письма капсулы времени не выдаются получателю до серверного срока открытия. Автор может удалить своё письмо.
- Общая история, достижения по фактическим прохождениям, звёзды, украшения, избранные игры, имена/цвета профиля, необязательные синтезированные звуки.
- Cinema Date: восемь вопросов, совместные ограничения, встроенная фильмотека реальных фильмов с поиском, жанрами и продолжительностью, независимые оценки, совпадения, общая серверная рулетка, согласование выбора, один повтор по обоюдному согласию, PNG-билет, история просмотров, прогнозы и отзывы.
- Приватные комнаты не индексируются. Секреты сессии в клиентские ответы не попадают. Приглашение другому человеку пользователь отправляет самостоятельно.

## Выбор фильма

Фильмотека встроена в сайт: внешние плагины, API и ключи не требуются. По умолчанию 90–150 минут; боевики и их жанровые сочетания исключены, ужасы — только по явному выбору. Учитываются ответы обоих зрителей, жанры, эпоха и длительность. Личные голоса скрыты до завершения голосования; veto исключает фильм из общих совпадений. Рулетка и сохранение билета требуют согласия двоих. Видеофильмы приложение не транслирует.

## Хранение и безопасность

D1: `rooms`, `movie_cache`, `rate_limits`. Записи комнат обновляются атомарно по `revision`, с повторением при конфликте. Игровые действия привязаны к ID игры/раунду, киновыбор — к ID сеанса/результата. Подготовленная подборка отклоняется, если киноанкета или дата успела измениться. Лимиты запросов, ограничение размера ввода, проверка Origin, cookie SameSite=Strict. Пароли и отдельная регистрация приложению не нужны. Шестизначный код является приглашением: передавайте его только вашему человеку.

## Проверка

```sh
node --experimental-strip-types --test tests/*.test.ts
node node_modules/typescript/bin/tsc --noEmit
node /root/.codex/plugins/cache/openai-curated-remote/sites/1.1.1/scripts/build-site.mjs
node --import ./scripts/sites-env.mjs tests/server-integration.mjs
```

Последняя команда поднимает изолированный тестовый Worker через Miniflare без браузерного сервера, применяет миграции к временной D1 и проверяет два независимых клиента, десять одновременных переходов, приватность, восстановление, лимит участников, CSRF и полный выбор реального фильма без внешних ключей. Рабочий каталог содержит реальные фильмы; служебные фикстуры тестов в него не включены.

Миграции: `drizzle/`; источники: `app/`, `lib/`; схема: `db/schema.ts`; конфигурация: `.openai/hosting.json`. Изменения публикуются поддерживаемым Sites workflow. `.env*` и локальные runtime-файлы не коммитятся.

PWA manifest позволяет установку в поддерживающих браузерах; работа сервера и игр требует интернета. Анимации учитывают prefers-reduced-motion.

## Новые приключения и фильмотека

Подкидной «Дурак» и шесть режимов: две правды и ложь, запретное слово, ассоциации, сложный выбор, угадай число, история на двоих. Сервер проверяет роли и ходы, скрывает секреты и сохраняет результаты. Рассказ можно перечитать в воспоминаниях.

Cinema Date содержит 302 фильма, 283 постера и 297 оценок зрителей TMDB. На карточках показаны короткие описания, в деталях — источник и дата снимка оценки. Есть сортировка по рейтингу и минимальная оценка. Отсутствующие фото и оценки честно заменяются заглушкой. Источники и лицензии: `docs/movie-data-sources.md`.

Cinema Date использует встроенный редакционный каталог (`lib/movie-library.ts`), без внешних API и секретов. Метаданные содержат год (без вымышленной точной даты), хронометраж киноверсии, жанры и оригинальные короткие описания. Нет вымышленных рейтингов и обещаний доступности на платформах. Поиск трейлера/просмотра открывается по желанию пользователя.

## Две соревновательные игры

«Угадай цену моего согласия»: шесть раундов с чередованием ролей, тайная сумма или отказ, одна догадка и до 100 очков за точность. 24 предложения, шесть случайных без повторов за партию.

«Аукцион суперспособностей»: 100 игровых монет каждому, пять закрытых торгов из 20 способностей, оплачивается только выигранная ставка. При равенстве приоритет чередуется. Бесплатная способность позволяет участвовать даже без покупок. Затем три испытания из 15: скрытые планы с одной-двумя своими силами и независимые оценки чужого плана от 1 до 5. Победитель определяется по очкам, монеты — только для торгов.

Обе игры хранятся на сервере, проверяют ID партии и номер хода, скрывают чужие незавершённые ответы, сохраняют подробную историю и дают пять общих звёзд за прохождение. Оценки в аукционе субъективны и выставляются участниками.

## Банка ваших приколов

Общая коллекция до 200 фраз и историй по 500 символов, с контекстом, автором фразы, датой и отметками любимого для каждого участника. Поиск, фильтр любимых и случайное воспоминание. Удалять можно только свои записи. Клиентский ID и серверная проверка делают повторную отправку безопасной. Старые комнаты поддерживаются без миграции.

## Маленькие знаки внимания

На главной странице комнаты: «Мне тебя не хватает», «Обнимаю», «Горжусь тобой». Вторая сессия получает карточку при открытом сайте или следующем входе. Можно принять сердечко или обнять в ответ. Сохраняется только последнее сердечко каждого участника; повторное отправление ограничено 30 секундами. Ответ и подтверждение обрабатываются атомарно. Это сообщения внутри приложения, без браузерных push-уведомлений.

## «Мы рядом»: один планшет на двоих

Открывается без комнаты и второго аккаунта. Три игры: «Слепой художник» (рисование пальцем или стилусом, отмена штриха, сохранение PNG), «Не засмейся» (30 секунд и честная ручная оценка), «Озвучка на двоих» (импровизация с поворотом на середине). Отдельные игры состоят из четырёх раундов с чередованием ролей.

«Собрать нам вечер» предлагает пять шагов под настроение: игры, тёплые задания и выбор одного из трёх фильмов с постерами, описаниями и оценками. Крупные кнопки, фокусный экран, пауза и скрытие секретного задания при передаче планшета. Таймер опирается на абсолютный срок, поэтому уход с вкладки не прибавляет времени.

Текущий вечер и три последних завершённых сохраняются только в localStorage этого браузера. Это не общая серверная история: очистка данных браузера удалит её. Рисунки можно отдельно скачать в PNG. Новая игра начинается только по явному нажатию.

### Ещё четыре игры для одного планшета

В «Мы рядом» добавлены: «Суд над нами» (три дела, обвинение и защита по 45 секунд, совместный приговор), «Ограбление века» (четыре сгенерированных замка за 20 минут с раздельными инструкцией и панелью, ошибка −30 секунд, подсказка −60), «Я тебя переиграю» (шесть раундов скрытых решений с автоматическим счётом) и «Пульт друг от друга» (четыре сцены с выбранными друг для друга ролями и поворотом на середине двухминутной сцены).

Текущая игра этого блока сохраняется отдельно в localStorage (`two-extra-v1`); восстановление повторно проверяет журнал действий. Выход к играм ставит таймер на паузу. Это игры для передачи одного устройства: скрытые экраны защищают от случайного просмотра, а не от технического доступа к данным браузера. Очки в дуэли игровые, без денег и ставок на деньги.

### Мини-арена: одновременные аркады

Раздел «Мы рядом» теперь включает «Мини-арену»: неоновый аэрохоккей на двоих до пяти голов; сумо на 2–4 игроков до трёх побед; танки с укрытиями и двумя жизнями на раунд на 2–4 игроков; реакция с фальстартами на 2–4 игроков до пяти очков. Это оригинальные canvas-игры с одновременным управлением на одном устройстве, без ботов и без второго аккаунта.

В хоккее каждый двигает биту в своей половине. В сумо и танках отпускание кнопки вращает персонажа, удержание двигает его вперёд; танк также стреляет. Касания учитываются отдельно по pointerId, есть захват указателя и обработка отмены. Для клавиатуры предусмотрены A/L/F/J и WASD/стрелки в хоккее.

Симуляция с фиксированным шагом 1/120 секунды, счёт и снимок текущего матча сохраняются в localStorage (`two-arcade-v1`). Уход со вкладки, потеря фокуса и выход к играм включают паузу и сбрасывают удержания. Перед стартом и продолжением идёт трёхсекундный отсчёт. После перезагрузки активный матч восстанавливается на паузе, без скачка игрового времени.

«Микро-гонки»: пятая аркада, 2–4 человека одновременно на овальной трассе. Машинка едет сама; удержание кнопки ведёт внутрь, отпускание — наружу. Внутренняя полоса чуть быстрее, препятствия и столкновения сбрасывают скорость. Первый после трёх кругов выигрывает. Прогресс, полосы, скорость и штрафы восстанавливаются вместе с матчем на паузе.

### Кубок на вечер и управление на планшете

«Кубок на вечер» объединяет реакцию, сумо и гонки в случайном порядке на 2–4 игроков. Каждый этап играется до первой победы (в гонке — три круга), победитель получает одно очко; при одновременной победе очко получает каждый победитель. Общая таблица, текущий этап и законченный кубок сохраняются вместе с матчем. Завершённый этап нельзя зачесть повторно, а восстановление проверяет соответствие матча этапу.

У гонок теперь отдельные камеры для каждого игрока: машинки не перекрывают друг друга, видны место, круг и шкала прохождения. Расчёт результата остался общим и одинаковые действия по-прежнему дают одинаковый результат.

Удержания пальцев и клавиатуры учитываются по источникам: отпускание одного пальца не отменяет другой палец или клавишу того же игрока. Короткие задержки кадров больше не замедляют игру на планшете с 10–20 кадрами/с; пауза длиннее 0,5 секунды останавливает матч и сбрасывает удержания. Старые сохранения индивидуальных аркад поддерживаются.

### Новые механики во всех пяти аркадах

- Гонки: бирюзовые стрелки дают ускорение на 1,25 секунды, каждая стрелка срабатывает один раз за проезд. Препятствие сбивает ускорение. Бонусы сохраняются вместе с матчем.
- Сумо: новое нажатие даёт рывок с коротким повышением предельной скорости; восстановление — 1,7 секунды. Кольцо вокруг бойца и кнопка показывают готовность.
- Танки: один рикошет снаряда от внешней стены, три симметричных расположения укрытий, след снаряда и вспышка попадания. Старые сохранения сохраняют прежнюю карту до следующего раунда.
- Реакция: короткие жёлтые обманные сигналы перед настоящим зелёным. Нажатие на жёлтый остаётся фальстартом.
- Хоккей: световой след шайбы, ограничение скорости и автоматическое выведение из полной остановки. Механика нормального прохода в ворота сохранена.

### Новые настольные игры в «Рядом»

В начале категории доступны три игры на одном планшете: мини-гольф на двоих (три поля, отскоки, прицеливание пальцем и ползунками, до восьми ударов на лунку), «Захват клеток» (поле 5×4, захват двух клеток одним ходом, дополнительный ход за клетку) и кооперативная «Память на двоих» (10 пар, общий счёт попыток). Партия сохраняется отдельно от аркады; мини-гольф ставится на паузу при уходе с вкладки, движение мяча восстанавливается без повторного удара. Есть правила, результат, реванш и управление с клавиатуры для кнопок и ползунков.
